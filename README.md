# 목소리 메시지 앱 (Voice Message App)

군 복무 중 특별한 순간들을 목소리로 기록하고, 정해진 시간에 재생할 수 있는 웹 애플리케이션입니다.

## 주요 기능

✅ **목소리 녹음** - 특정 상황(아침, 식사, 취침 등)에서 메시지 녹음
✅ **클라우드 동기화** - Firebase를 통한 안전한 데이터 저장
✅ **자동 재생** - 설정된 시간에 자동으로 메시지 재생
✅ **갤러리 뷰** - 녹음된 모든 메시지 확인
✅ **디데이 카운팅** - 전역일, 휴가일까지 남은 날짜 표시

## 기술 스택

- **Frontend**: React + TypeScript
- **Backend**: Firebase (Firestore, Cloud Storage, Authentication)
- **Audio**: Web Audio API
- **Styling**: Tailwind CSS
